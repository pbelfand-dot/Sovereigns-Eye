# Sovereign's Eye

Game project repository for **Sovereign's Eye**.

## 3D asset library

The [`3D/`](3D/) folder contains a ready-to-use, cartoony medieval starter library:

- Five recommended non-Kenney style packs with 496 models
- Three rejected Kenney comparison packs retained for audit/reference
- 18 original animated blocky character models, retained as a legacy option
- 76 castle, siege, terrain, and decoration models
- 167 fantasy-town, road, nature, prop, and water-feature models
- 176 textured Quaternius village modules for the chosen visual direction
- 10 sleek Quaternius character-test models with embedded textures
- Both Quaternius Universal Animation Library Standard editions: 86 clips total, with in-place and root-motion exports
- Per-model previews for the original collections and overview galleries for larger packs
- Source, license, checksum, dependency, and validation records

All 1,218 cataloged model files use the widely supported glTF 2.0 format. The source packs are
released under CC0, so they can be used and modified in commercial or non-commercial
games without an attribution requirement. Start with the
[`3D/alternatives/`](3D/alternatives/) comparison to choose a visual direction, then
see [`3D/README.md`](3D/README.md) for the complete catalog and import notes.

The selected environment foundation is the Quaternius Medieval Village MegaKit;
its 176 free Standard modules are in
[`3D/environments/quaternius-medieval-village-standard/`](3D/environments/quaternius-medieval-village-standard/).
See the [`scalability roadmap`](3D/research/SCALABILITY_ROADMAP.md) for what is ready
from hamlet through kingdom scale and which ship, landmark, population, and nature
assets are still needed.
