# Universal Animation Library 1 — Standard

The first library is the core general-purpose set: directional locomotion,
crouching, jumping, swimming, sitting, deaths, interactions, carrying, basic
melee and gun actions, emotes, and other everyday character movement.

- Official page: https://quaternius.com/packs/universalanimationlibrary.html
- Itch download: https://quaternius.itch.io/universal-animation-library
- Edition: Standard (free)
- Updated source archive: June 16, 2026
- License: CC0 1.0

`UAL1_Standard.glb` is the in-place export. `UAL1_Standard_RM.glb` is the same
43-clip Standard selection with root motion baked into movement clips.
