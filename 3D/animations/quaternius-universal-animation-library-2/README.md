# Universal Animation Library 2 — Standard

The second library complements the first with more specialized fantasy-game
actions: multi-hit melee and sword combos, blocking and shield movement,
parkour and slides, farming and fishing actions, carrying, and zombie movement.

- Official page: https://quaternius.com/packs/universalanimationlibrary2.html
- Itch download: https://quaternius.itch.io/universal-animation-library-2
- Edition: Standard (free)
- Updated source archive: June 16, 2026
- License: CC0 1.0

`UAL2_Standard.glb` is the in-place export. `UAL2_Standard_RM.glb` is the same
43-clip Standard selection with root motion baked into movement clips.

`Mannequin_F.glb` is a female retargeting reference supplied in the Standard
archive. It intentionally contains no animation clips; use the engine's humanoid
retargeter to transfer animations from either UAL2 file.
