# Option 03 — Kenney Graveyard

**Direction:** gothic, spooky storybook world. **Models:** 91 GLBs.

Choose this if Sovereign's Eye should feel mysterious and slightly dark without
becoming realistic horror. It provides a coherent environment, props, vegetation,
structures, and characters. Its main risk is a Halloween-specific tone, which can be
softened by recoloring and mixing it with neutral castle scenery.
