# Option 04 — KayKit Medieval Hexagon

**Direction:** colorful medieval overworld and settlement kit. **Models:** 221 GLBs.

This is the strongest replacement for the previous town and platformer choices. It
contains castles, houses, mills, markets, roads, rivers, coasts, trees, mountains, and
settlement props in a coherent rounded style. Color variants support factions.

- Source: [KayKit Medieval Hexagon Pack 1.0](https://github.com/KayKit-Game-Assets/KayKit-Medieval-Hexagon-Pack-1.0)
- License: CC0 1.0; see `LICENSE.txt`
- `models/`: complete pack, converted from glTF to self-contained GLB without redesigning the meshes or materials
- `previews/`: official buildings, nature, tile, and scene galleries
