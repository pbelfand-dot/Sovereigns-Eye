# Option 04 — Kenney Platformer

**Direction:** bright, rounded mascot adventure. **Models:** 153 GLBs.

This is the broadest single option for quickly building readable levels. It includes
characters, terrain blocks, hazards, foliage, signs, props, and interactive-looking
objects. The cheerful palette is immediately approachable, but may need a more royal
or dramatic color pass for Sovereign's Eye.
