# Option 05 — KayKit Halloween Bits

**Direction:** gothic fantasy scenery in the same rounded art family. **Models:** 63 GLBs.

This pack adds a darker region without changing the core art style: crypts, shrines,
grave markers, wrought-iron fences, bare trees, lanterns, candles, bones, and pumpkins.
Used selectively, it can define corrupted territory rather than a purely seasonal map.

- Source: [KayKit Halloween Bits 1.0](https://github.com/KayKit-Game-Assets/KayKit-Halloween-Bits-1.0)
