# Option 03 — KayKit Dungeon Remastered

**Direction:** rounded modular fantasy interiors. **Models:** 203 GLBs.

This pack supplies the interior half of the Sovereign's Eye world: walls, floors,
stairs, doors, cells, scaffolding, furniture, treasure, banners, alchemy props, and
traps. Its materials and proportions align with the KayKit characters.
