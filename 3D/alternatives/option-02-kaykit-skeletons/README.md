# Option 02 — KayKit Skeletons

**Direction:** stylized undead enemies. **Models:** 4 animated GLBs.

This pack is the strongest enemy companion to option 01. It keeps the same rounded,
readable proportions while supplying Mage, Minion, Rogue, and Warrior silhouettes.
The tradeoff is that it is a faction pack, not a complete hero or civilian cast.

- Source: [KayKit Character Pack: Skeletons 1.0](https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Skeletons-1.0)
- License: CC0 1.0; see `LICENSE.txt`
- `models/`: Mage, Minion, Rogue, and Warrior skeletons
- `previews/`: one image per model plus `overview.png`
- `models/source-textures/`: original texture sheet for repainting; the distributed GLBs embed their textures
