# Option 01 — KayKit Adventurers

**Direction:** rounded, heroic fantasy characters. **Models:** 5 animated GLBs.

This is the recommended primary direction for Sovereign's Eye. The characters have
clear, non-cubic silhouettes, expressive oversized features, and extensive animation
libraries suitable for combat and traversal. The main tradeoff is the compact starting
cast and deliberately cute/chibi proportions.

- Source: [KayKit Character Pack: Adventures 1.0](https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Adventures-1.0)
- License: CC0 1.0; see `LICENSE.txt`
- `models/`: Barbarian, Knight, Mage, Rogue, and Hooded Rogue
- `previews/`: one image per model plus `overview.png`
- `models/source-textures/`: original texture sheets for repainting; the distributed GLBs embed their textures
